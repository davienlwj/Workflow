                    intervals.icu sync (via Zepp)

                    Automatically imports your runs from intervals.icu, and shows your most recent Resting HR and Sleep as Dashboard stat tiles. Connect your Zepp/Amazfit account directly on a free intervals.icu account (intervals.icu → Settings → Amazfit → sign in with Zepp), then paste your intervals.icu API key below. Runs only - cycling, stairmaster, elliptical, rowing and skiing sessions aren't auto-imported, so log those (and any lift workouts) by hand from the Session type picker. No backend or paid API needed, just your own free API key - see the app's README.

                    Not connected.

                    Watch workout sync

                    Pulls in workouts logged on the Amazfit T-Rex 3 Pro companion app (see hybrd-watch/ in this repo) via a private GitHub Gist you own - no backend, just a personal access token. Create a secret gist with one file named "hybrd-workouts.json" containing {"workouts":[]}, then a personal access token with the "gist" scope (github.com → Settings → Developer settings → Personal access tokens). Paste both the Gist ID (from its URL) and the token here, and the same two values into the watch app's Zepp settings. Read-only from here - nothing is ever written back to the gist.
